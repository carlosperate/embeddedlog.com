# Vendored Shariff assets

Shariff **3.3.1**, extracted unchanged from `shariff/shariff-3.3.1/` in:

https://github.com/ojsde/shariff/releases/download/v3_5_0-1/shariff-3_5_0-1.tar.gz

Archive SHA-256:
`1fb5d83880397102759421e65034a9c10c58cf8d9ac4627d90d81787991832a4`

The OJS plugin version and the bundled browser-library version differ. Only
the browser assets are used here; no OJS/PHP plugin files are installed.

Files:

- `shariff.min.css`: Shariff CSS without Font Awesome styles.
- `../../js/shariff.min.js`: Shariff JavaScript without bundled jQuery.
